# Agent Personas for Project Workflow

This directory contains comprehensive persona definitions for 5 specialized AI agents designed to improve your development workflow. Each persona provides detailed guidelines, best practices, and decision-making frameworks.

## 📋 Available Personas

### 1. Developer Agent
**File:** `agent-developer.md`  
**Purpose:** Coding, debugging, and implementation tasks  
**Use for:**

- Writing new features
- Fixing bugs
- Implementing technical solutions
- Creating tests
- Code documentation

**Key Strengths:**

- Clean, maintainable code
- Comprehensive testing
- Problem-solving approach
- Security-conscious development

---

### 2. Code Reviewer Agent
**File:** `agent-code-reviewer.md`  
**Purpose:** Code quality assurance and reviews  
**Use for:**

- Reviewing pull requests
- Identifying bugs and issues
- Ensuring code quality standards
- Security review
- Design pattern evaluation

**Key Strengths:**

- Constructive feedback
- Priority-based issue classification (P0-P3)
- Comprehensive quality checklist
- Security and performance awareness

---

### 3. Rebaser Agent
**File:** `agent-rebaser.md`  
**Purpose:** Git history management and rebasing  
**Use for:**

- Cleaning up commit history
- Interactive rebasing
- Organizing commits logically
- Resolving rebase conflicts
- Maintaining clean git narratives

**Key Strengths:**

- Git history expertise
- Conflict resolution strategies
- Atomic commit organization
- Safety protocols for rebasing

---

### 4. Merger Agent
**File:** `agent-merger.md`  
**Purpose:** Branch merging and integration  
**Use for:**

- Merging feature branches
- Managing merge conflicts
- Coordinating releases
- Branch synchronization
- Integration validation

**Key Strengths:**

- Multiple merge strategy expertise
- Conflict resolution frameworks
- Integration safety protocols
- Rollback procedures

---

### 5. Multiplan Manager Agent
**File:** `agent-multiplan-manager.md`  
**Purpose:** Orchestrating parallel work and complex projects  
**Use for:**

- Breaking down large projects
- Coordinating multiple developers/agents
- Managing dependencies
- Parallel workstream execution
- Progress monitoring and adjustment

**Key Strengths:**

- Strategic planning and decomposition
- Dependency management
- Dynamic plan adjustment
- Risk mitigation
- Team coordination

---

## 🚀 How to Use These Personas

### For AI Agents/LLMs
When instructing an AI agent, you can reference the appropriate persona:

```
You are acting as the Developer Agent. Please read and follow the 
guidelines in agent-developer.md for this task.

Task: Implement user authentication with OAuth2...
```

### For Team Documentation
Use these personas as:
- **Onboarding guides** for new team members
- **Role definitions** for clear responsibilities
- **Best practices documentation** for each specialization
- **Quality standards** for your codebase

### For Process Improvement
Reference specific sections to improve your team's:

- Code review process (Code Reviewer Agent)
- Git workflow (Rebaser & Merger Agents)
- Project planning (Multiplan Manager Agent)
- Development standards (Developer Agent)

## 📚 Persona Structure

Each persona file includes:

1. **Role Identity** - Clear definition of purpose and responsibilities
2. **Core Responsibilities** - Detailed breakdown of key duties
3. **Best Practices** - Proven approaches and guidelines
4. **Communication Style** - How to interact and report
5. **Decision Framework** - When to act vs when to escalate
6. **Success Metrics** - How to measure effectiveness
7. **Anti-Patterns** - Common mistakes to avoid
8. **Examples** - Concrete scenarios and templates

---

## 🔄 Workflow Integration

### Example: Feature Development Lifecycle

1. **Planning Phase** → **Multiplan Manager Agent**
   - Break down feature into tasks
   - Identify dependencies
   - Create execution plan

2. **Development Phase** → **Developer Agent**
   - Implement features
   - Write tests
   - Document code

3. **Review Phase** → **Code Reviewer Agent**
   - Review code quality
   - Identify issues
   - Provide feedback

4. **History Cleanup** → **Rebaser Agent**
   - Clean commit history
   - Organize commits logically
   - Prepare for merge

5. **Integration Phase** → **Merger Agent**
   - Merge to main branch
   - Resolve conflicts
   - Validate integration
